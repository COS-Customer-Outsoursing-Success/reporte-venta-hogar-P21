# Reglas de Comportamiento del Agente

## Consola y Comandos del Sistema
- El usuario utiliza exclusivamente **CMD (Símbolo del sistema / Command Prompt)** de Windows, NO PowerShell.
- Siempre proporciona comandos, instrucciones o scripts compatibles con **CMD** (`cmd.exe`).
- Al sugerir comandos de terminal al usuario, utiliza el formato de código `cmd` o `bat` en lugar de `powershell`.
